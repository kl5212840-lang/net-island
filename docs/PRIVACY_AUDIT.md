# Net Island 隐私检查与封闭记录

检查日期：2026-10-22 至 2026-10-23。范围：本仓库应用源码、Now Playing 适配器、Helper、构建依赖与当前个人版的联网行为。基线为 `e11aa23f`，本文和封闭实现随同一次提交保存。结论不适用于以后未经审查的代码或其他应用。

## 结论与执行策略

源码检查未发现独立的第三方埋点、广告或崩溃遥测 SDK。Swift Package 没有远程软件包依赖，Now Playing 适配器为仓库内源码。但上游确实含有文件上传、反馈发送、歌曲信息查询及账户查询等对外接口；它们有明确功能用途，不等于恶意外传。个人版现以不可由用户偏好或备份导入解除的编译内策略关闭这些入口。

`Sources/Vorssaint/Core/NetworkPrivacy.swift` 集中规定：禁止内容上传、可选远程元数据及云端 AI 账户查询。功能入口提前返回；相关 URLSession 同时安装本地拒绝协议，作为第二层拦截。旧的开启偏好无效。界面说明禁用原因，截图、录屏保留本地保存/导出，歌词保留本地导入，封面保留系统播放元数据中已有的图片，AI 用量保留本地日志读取。

这不是系统防火墙，也不是“所有网络绝对为零”的承诺。下文明确列出主动操作和平台服务边界。

## 已检查的外联类别

| 接口/目的 | 原先可能发送的信息 | 触发方式 | 本版本处理 |
|---|---|---|---|
| `screenshots.vorssaint.com/v1/screenshots` | PNG 截图内容 | 点击临时链接分享，或启用后使用上传快捷键 | 禁止创建/上传；编辑器按钮、快捷键及设置入口关闭 |
| 同域 `/v1/recordings` | 导出的 MP4 录屏内容 | 用户创建临时分享链接 | 禁止创建/上传，保留本地导出 |
| 同域 `/v1/feedback` | 反馈文字；可选应用版本、系统版本、机型、语言、更新通道 | 提交反馈；诊断原本是可选项 | 禁止发送，反馈窗口说明关闭原因 |
| `lrclib.net`、`musicbrainz.org` | 歌名、艺人、专辑等查询信息，服务器可见连接 IP | 原本开启在线歌词后随播放查询 | 关闭；只支持本地歌词导入 |
| `itunes.apple.com/search`、`i.ytimg.com` | 歌曲搜索词或 YouTube 视频标识，连接 IP | 原本启用浏览器封面补全后自动查询 | 关闭；同时阻止为补全封面读取浏览器会话文件 |
| 轮盘菜单目标站点 `/favicon.ico` | 目标域名、IP、请求时间 | 编辑/添加网址获取图标 | 关闭下载；保留本地图标/默认图标 |
| GitHub/raw.githubusercontent.com 上游价格表 | 常规 GET 请求、IP、版本 User-Agent；不含使用记录 | AI 分区运行时定期刷新价格 | 关闭；使用应用内置/已缓存价格，价格可能过时 |
| Apple 应用查询、Homebrew 目录、应用发布者 feed | 已安装应用的 bundle ID、应用标识、国家/系统版本等 | 第三方应用更新扫描，含自动任务 | 停止扫描和定时器，联网会话拒绝请求 |
| GitHub 应用自身更新及展示视频 | 版本查询、更新资源请求 | 自动/手动更新与更新展示 | 自更新原有硬关闭保持；视频下载增加独立阻断 |
| Claude/Codex 外部 CLI 账户查询 | 由 CLI 使用它自己的账户凭据查询用量/限额；原代码不发送对话提示词 | AI 分区账户限额刷新/账户操作 | 阻止启动这些 CLI 会话；账户在线功能不可用 |
| Homebrew 流行度统计 JSON | 获取公开汇总数据的 GET 请求；这不是上传本机统计 | 搜索列表加载流行度 | 停止请求 |
| Homebrew 自身 analytics | 由外部 brew 决定的命令/包统计 | 本应用运行 brew | 进程环境及 Terminal 回退强制 `HOMEBREW_NO_ANALYTICS=1`；同时阻止隐式自动更新 |

所有正常 HTTPS 连接都可能向对方暴露出口 IP 与时间；“只下载”并不意味着没有隐私影响。

## 明确保留的联网操作

- **主动测速**：`SpeedTest.swift` 只在开始测速时连接 `speed.cloudflare.com`。上传数据为新建的零字节缓冲区，不读取文件或剪贴板。服务器仍能看到 IP 和测速流量。
- **主动 Homebrew 操作**：安装、搜索、升级、主动更新 Homebrew 会调用用户的 brew，并可能下载元数据/软件。禁用 analytics 不是外部 brew 的完整沙箱；其 tap、包安装脚本及用户 shell 配置仍在原信任边界内。本应用不会替用户安装未知包。
- **在浏览器打开链接/系统分享面板/用户配置的脚本或快捷指令**：由用户发起，交给系统或其他应用处理；不能承诺外部应用的后续行为离线。
- **撤销历史分享链接**：仅用户点击删除时允许 HTTPS DELETE 到上述分享域名的两种固定 `/v1/.../<32字符ID>` 路径；不允许 GET/POST、其他域名、端口、账户信息、查询参数或重定向，防止删除凭据被导向其他站点。没有自动撤销或销毁用户记录。
- macOS 本身的权限、签名校验、系统云剪贴板、网络文件卷等不是本应用 URLSession 过滤器管理的流量。

## 本地数据与权限

网速读取本机接口计数，CPU/内存等监测同样是本机采样，没有必要为这些功能上报数据。网络地址功能只读取本机接口，不调用公网 IP 查询服务。

剪贴板、临时分享删除凭据、截图/录屏、便笺、AI 用量等本地记录可能敏感。`PrivateFileStore` 对其管理的目录使用 `0700`，文件使用 `0600`，并原子写入；这不是文件内容加密。用户导出的文件、系统偏好与第三方程序文件不全由这个存储器管理。同一登录用户权限下的其他程序及已获授权的管理者仍可能读取数据。

本应用为本地签名、非 App Sandbox 的系统工具，并可能获得辅助功能、屏幕录制等较强权限。此检查保留用户配置与必要权限，没有清空历史，也没有扩大系统权限。应按需要启用功能、清理敏感历史，并保持对这份源码和构建的控制。

## 验证方法与限制

- 检索全部 `URLSession` / `URLRequest` / HTTP 方法 / 上传、下载、socket、curl、外部进程，以及可接收 URL 的图片和 Data 加载路径。图片/文件路径检查覆盖应用资源、私有存储、用户选择的本地文件；蓝牙连接与 XPC 不误归类为公网上传。
- 审阅文件上传请求体、反馈字段、歌词参数、应用清单查询、CLI 参数、Homebrew 环境与 Now Playing 适配器。未借检查之名上传任何用户内容，也没有实际向分享/反馈服务器发送测试文件。
- 自动回归测试检查硬策略、非法撤销目标、上传的本地失败回调、Homebrew 环境覆盖与代理保留。开发版及发布版自检在开启旧联网偏好的条件下验证保护仍然生效。
- 安装后检查进程、签名及短时 TCP/UDP 连接快照。瞬时无连接只能说明观察窗口，不能证明任意未来路径均无外联。未进行系统级全量抓包、第三方渗透测试或未来代码审计。

官方接口依据：[Apple URLSessionConfiguration.protocolClasses](https://developer.apple.com/documentation/foundation/urlsessionconfiguration/protocolclasses)，[Homebrew analytics opt-out](https://docs.brew.sh/Analytics)。
